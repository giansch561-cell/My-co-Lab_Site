# My-Co-Lab Roadmap

## Visão

Criar uma plataforma de referência sobre cogumelos que reúna informação científica, documentação prática, experiências próprias e conteúdos educativos, tornando-se uma fonte de conhecimento acessível para qualquer pessoa interessada no mundo dos fungos.

O desenvolvimento será feito de forma gradual: primeiro criar uma base sólida, depois publicar e, por fim, melhorar continuamente o projeto.

# Futuro

Quando a versão inicial estiver publicada poderão ser adicionadas novas funcionalidades, como:

- Website multilíngue
- Loja online
- Área de membros
- Newsletter
- Cursos
- Biblioteca digital
- Ferramentas para produtores

Estas funcionalidades não fazem parte da versão inicial e serão avaliadas no momento adequado.
